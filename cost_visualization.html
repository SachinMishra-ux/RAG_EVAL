📐 2. Formal Mathematical Cost Formulation

The exact formula used in eval_cost.py and eval_ops.py for cost accounting.

Standard Provider Pricing Equation
$$\text{Cost}_{\text{query}} = \left( \frac{N_{\text{uncached}}}{10^6} \times P_{\text{in}} \right) + \left( \frac{N_{\text{cached}}}{10^6} \times P_{\text{cached}} \right) + \left( \frac{N_{\text{out}}}{10^6} \times P_{\text{out}} \right)$$
• \(N_{\text{uncached}}\): Raw input prompt tokens (user question + retrieved contexts + instructions).
• \(N_{\text{cached}}\): Prompt tokens reused from persistent KV-cache (discounted by 50% on supported models).
• \(N_{\text{out}}\): Tokens generated in synthesis answer response.
• \(P_{\text{in}}, P_{\text{out}}\): Published API tariffs per 1 Million (1,000,000) tokens.
