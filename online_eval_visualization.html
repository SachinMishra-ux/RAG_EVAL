⚖️ 1. Offline vs. Online Evaluation: Conceptual Foundation

Understanding why offline CI/CD regression suites and continuous online monitoring are both essential.

🧪 Offline Evaluation (Pre-Deployment) Deterministic CI/CD

Evaluates the system against a static Golden Ground-Truth Dataset before merging code or deploying to production.

  • ✔ Data source: Static JSON goldens with pre-verified answers.
  • ✔ Execution: Triggered via git hooks or pre-push test suites.
  • ✔ Goal: Prevent regressions in recall, precision, and safety prior to release.
🛰️ Online Evaluation (Live Production Monitoring) Continuous Telemetry

Continuously monitors unseen queries from real humans. Because there are no pre-written ground truth labels, it evaluates live outputs using Reference-Free Metrics.

  • ✔ Data source: Live user requests streamed to LangSmith.
  • ✔ Execution: Asynchronous background daemon (does not block user responses).
  • ✔ Goal: Detect production hallucinations, drift, and relevance drop-offs.

📐 3. The Online RAG Triad Metrics

How each live trace is judged without needing human-written ideal answers.

1. Faithfulness Hallucination Guard
Context ⟷ Answer

Checks if every factual claim made in the generated answer is directly grounded in the retrieved chunks.

Score = Claims Grounded / Total Claims
2. Answer Relevancy Quality Guard
Question ⟷ Answer

Verifies that the generated response directly answers the user's specific question without wandering off-topic.

Score = Relevant Points / Target Points
3. Contextual Relevancy Noise Guard
Question ⟷ Context

Measures whether the vector database retrieved chunks that actually pertain to the question or pulled irrelevant noise.

Score = Pertinent Sentences / Total Sentences
